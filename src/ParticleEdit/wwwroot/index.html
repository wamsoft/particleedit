画面の見かた

左がプレビュー、右がパラメータです。スライダーを動かすとその場で作り直されて すぐ反映されます。パラメータはタブで分かれていて、選んだタブは次に開いたときも残ります。

座標と大きさ

プレビューは 1 ワールド単位 = 1 ピクセル / 画面中央が原点 / +Y が画面上方向。 見えている大きさと位置が、そのまま組み込み先のピクセル数になります。

枠は組み込み先の画面サイズ (既定 1280×720) です。枠が収まるよう全体を縮小して表示し、 倍率をラベルに出します。枠の中の十字が発生位置で、つかんで動かせます。 細かく合わせたいときは「発生」タブのスライダーで。

角度はどれも度で、反時計回り、90 度が画面の上方向です (方向・重力の向き・粒の回転・形の回転)。

発生位置を動かす

「動き」タブの 動かしかた で決めます。

動かさない発生位置は固定。既定
軌道を焼き込む選んだ軌道をエフェクトに埋めます。再生すればそう動くので、組み込み先のコードは要りません
組み込み先から動かす位置を差し込める形で書き出します。値は組み込み先が毎フレーム入れます

軌道の作りかた: 「記録…」を押してプレビューの上をドラッグします。 押している間の位置を毎フレーム拾うので、ゆっくりなぞればゆっくりな動きになります。 離すと名前を聞かれます。やめるときは Esc。軌道は何本でも持てて、 選んでいるものがプレビューに点線で重なります。

粒が軌跡として残るかどうかは「発生」タブの 発生位置を動かしたとき で決まります (既定は「その場に置き去り」= 軌跡になる)。発生位置を動かさないなら、どちらでも見た目は変わりません。

形

粒の形はパラメータから作ります。辺の数 0 で円、3 以上で多角形、星形の比率を下げると星。 プリセット (ぼかし円 / 円 / リング / 星 / 四角 / 六角 / 光芒) はこのパラメータの 組み合わせでしかないので、押してから自由に動かせます。

手持ちの画像も「画像を取り込む…」から使えます。2 の冪の正方形 (最大 512) に整えてから 送っています。Effekseer の WebGL ランタイムが 2 の冪でないテクスチャを勝手に縮めるため、 揃えておかないとプレビューと書き出しで見た目がずれるためです。

テンプレート

ヘッダの「テンプレート」から 12 種を出発点に選べます。気に入った状態は 「現在の設定を追加」で自分のテンプレートにできます。

保存とエクスポート

保存編集を再開するための形式。こちらが元データです
エクスポート配布用の一方向の書き出し。テクスチャを同梱した ZIP になります

パラメータから Effekseer のデータへの変換は逆算できないので、 書き出したファイルを読み戻してもスライダーの位置は分かりません。 直せなくなるので、元データのほうも必ず残してください。

efkzip吉里吉里プラグイン用。通常はこれ
efkランタイムに直接読ませる最小構成
efkefcEffekseer 公式エディタで開いて作り込みたいとき

置き場が particleedit.json で決めてあるときは、エクスポートがそのフォルダへ 直接ファイルを置きます (ブラウザからは保存先を選べないため)。決めていなければダウンロードになります。

組み込み先から動かす場合

「組み込み先から動かす」で書き出すと、発生位置を外から差し込める形になります。 吉里吉里プラグインなら名前でそのまま渡せます。

player.setDynamicInputByName("emitter.x", x)
player.setDynamicInputByName("emitter.y", y)

渡す座標は setCoord と同じ画面中央が原点・Y が下向きのピクセルです (符号合わせはエフェクト側に入っているので気にしなくて構いません)。名前の対応は ZIP に入る effect.json から読まれます。記録した軌道も motion/*.json として同梱されるので、どれを流すかは組み込み先で選べます。

思ったとおりに出ないとき

  • 小さくて目立たない … 効くのは「大きさ > 密度 (発生数 × 寿命) > 加算の重なり」の順です。発生数を上げるより粒を大きくするほうが安く効きます
  • 四角い塊に見える … 開始サイズのばらつきを増やすか、形のぼかしを上げてください
  • 粒の向きが揃わない … 回転を使うと角度の基準が進行方向になります。画面に対して固定したいときは回転のパラメータをすべて 0 に
  • 枠からはみ出す … 「表示」タブの画面サイズを組み込み先に合わせてから調整してください
