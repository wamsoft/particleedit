画面の見かた

左がプレビュー、右がパラメータです。スライダーを動かすとその場で作り直されて すぐ反映されます。パラメータはタブで分かれていて、選んだタブは次に開いたときも残ります。

発生いくつ・どこから・どちらへどれくらいの速さで出るか。重力と空気抵抗、ループもここ
粒1 粒の寿命・大きさ・回転
色色相・彩度・明度と、それぞれのばらつき。透明度
形粒の形と合成方法
表示背景色・背景画像・画面枠。エフェクトデータには入りません
動き発生位置そのものを動かす。軌道の記録と、再生側の操作を真似る確認用のつまみ

座標と大きさ

プレビューは 1 ワールド単位 = 1 ピクセル / 画面中央が原点 / +Y が画面上方向。 見えている大きさと位置が、そのまま組み込み先のピクセル数になります。

枠は組み込み先の画面サイズ (既定 1280×720) です。枠が収まるよう全体を縮小して表示し、 倍率をラベルに出します。十字が発生位置で、つかんで動かせます。 細かく合わせたいときは「発生」タブのつまみで。中央へ戻したいときは 同じタブの 発生位置を中央へ戻す を押します。

十字は「動き」タブの再生側の操作を掛けた後の位置に出ます (粒の出どころと一致します)。 ズームや回転を掛けていても、つかんで動かした量はそのぶん換算されるので指の動きとずれません。

角度はどれも度で、反時計回り、90 度が画面の上方向です (方向・重力の向き・粒の回転・形の回転)。

再生側の操作を真似る

「動き」タブの 再生側の操作 (確認用) は、組み込み先がエフェクト全体に 掛ける配置を真似るものです。吉里吉里プラグインなら setCoord / setZoom / angle にあたります。 エフェクトのデータには入りません。

ここを動かすと、平行移動には既に出ている粒が付いてこないのに、拡縮と回転は 付いてくるのが見えます (「その場に置き去り」のとき)。Effekseer が追従の判定を 平行移動 / 回転 / 拡縮で別々に持っているためで、組み込んでから気づくと厄介なので ここで確かめられるようにしてあります。

軌道を選んでいるときは、プレビュー左下にいまの発生位置が出ます。 「組み込み先から動かす」で書き出す場合も、エディタ側が値を差し込んで動かして見せます。

背景画像

「表示」タブの 背景画像… から、組み込み先の絵を敷いて見えかたを 確かめられます。中央に原寸で置くだけなので、枠と同じ寸法の絵なら ちょうど枠を埋めます。粒はその上に描かれます。

背景画像の明るさ を下げると粒が見やすくなります。 暗い背景の上で成立するか、明るい背景に負けていないか、といった確認に。

背景はエフェクトの一部ではないのでプロジェクトには保存されません。 代わりにブラウザが覚えているので、開き直しても残ります。「外す」で消えます。

発生位置を動かす

「動き」タブの 動かしかた で決めます。

動かさない発生位置は固定。既定
軌道を焼き込む選んだ軌道をエフェクトに埋めます。再生すればそう動くので、組み込み先のコードは要りません
組み込み先から動かす位置を差し込める形で書き出します。値は組み込み先が毎フレーム入れます

軌道の作りかた: 「記録…」を押してプレビューの上をドラッグします。 押している間の位置を毎フレーム拾うので、ゆっくりなぞればゆっくりな動きになります。 離すと名前を聞かれます。やめるときは Esc。軌道は何本でも持てて、 選んでいるものがプレビューに点線で重なります。

粒が軌跡として残るかどうかは「発生」タブの 発生位置を動かしたとき で決まります (既定は「その場に置き去り」= 軌跡になる)。発生位置を動かさないなら、どちらでも見た目は変わりません。

ループ

「発生」タブの 同じパターンを繰りかえす を入れると、 指定した周期ごとに発生をやり直すようになります。 発生する長さを周期より短くすると、 「どっと出て、消えて、また出る」という繰りかえしが作れます (周期と同じにすれば、いままでどおり出しっぱなしです)。

Effekseer 自体には「エフェクト全体をループ再生する」指定がありません (公式エディタの IsLoop はプレビュー用で、データには入りません)。 ここでは発生用のノードを周期ごとに作り直すことで繰りかえしにしています。 粒ごとの乱数は周回ごとに引き直されるので、1 周ごとに寸分たがわず同じ、にはなりません。

粒の寿命が周期より長いときは、前の周の粒が次の周へはみ出して重なります。 それでも繰りかえしは途切れません。焼き込んだ軌道と一緒に使うときは、 軌道の長さと周期を揃えてください (ずれていると 1 周ごとに位置がずれます)。

アニメパターン

ループを入れておくと、ヘッダの アニメパターン… から エフェクトを絵の連なりに焼けます。Effekseer のランタイムが要らなくなるので、 軽く済ませたいときや、プラグインを使わない場所で出したいときに。

シート PNG1 枚に格子状に並べたもの。矩形を切り替えて使います
連番 PNG1 コマ 1 枚。zip でまとめて出ます
amv吉里吉里の AlphaMovie プラグインが読む動画。コマ数が多いときはこれがいちばん小さくなります

継ぎ目のないループになります。 1 周期ぶんだけ発生するエフェクトを裏で作り、粒が消えるまで回してから、 周期ごとに折り返して重ねているためです。最後のコマから最初のコマへ戻っても飛びません。 焼く前に 試し焼き で繰りかえしを確かめられます (市松模様が透明なところです)。

なめらかさ はコマ数の決めかたです。エディタは 60fps 基準なので、 30 fps を選べば 2 フレームおきに 1 コマ焼かれて枚数が半分になります (見た目の速さは変わりません)。 1 コマの大きさは 画面サイズにする ボタンで 「表示」タブの画面サイズに合わせられます。焼く前でも、確認欄の点線がそのコマの大きさです。

写すのはプレビューの中央です。「動き」タブの再生側の操作 (位置・ズーム・回転) は掛かりません。 1 コマの大きさは 16 の倍数に丸められます (amv の決まりに合わせています)。 大きなコマを高いなめらかさで焼くと落ちるほどメモリを食うので、 見込みが大きすぎるときは焼く前に断ります (案内に必要量が出ます)。 色は加算のエフェクトでもアルファ付きで出るので、 組み込み先では加算合成でも通常合成でも使えます。

形

粒の形はパラメータから作ります。辺の数 0 で円、3 以上で多角形、星形の比率を下げると星。 プリセット (ぼかし円 / 円 / リング / 星 / 四角 / 六角 / 光芒) はこのパラメータの 組み合わせでしかないので、押してから自由に動かせます。ハートだけは辺の数では 表せない決まった形なので、辺の数と星形は効きません (ほかのつまみは使えます)。

手持ちの画像も「画像を取り込む…」から使えます。2 の冪の正方形 (最大 512) に整えてから 送っています。Effekseer の WebGL ランタイムが 2 の冪でないテクスチャを勝手に縮めるため、 揃えておかないとプレビューと書き出しで見た目がずれるためです。

テンプレート

ヘッダの「テンプレート」から 13 種を出発点に選べます。気に入った状態は 「現在の設定を追加」で自分のテンプレートにできます。

保存とエクスポート

保存編集を再開するための形式。こちらが元データです
エクスポート配布用の一方向の書き出し。テクスチャを同梱した ZIP になります

パラメータから Effekseer のデータへの変換は逆算できないので、 書き出したファイルを読み戻してもスライダーの位置は分かりません。 直せなくなるので、元データのほうも必ず残してください。

efkzip吉里吉里プラグイン用。通常はこれ
efkランタイムに直接読ませる最小構成
efkefcEffekseer 公式エディタで開いて作り込みたいとき

置き場が particleedit.json で決めてあるときは、エクスポートがそのフォルダへ 直接ファイルを置きます (ブラウザからは保存先を選べないため)。決めていなければダウンロードになります。

組み込み先から動かす場合

「組み込み先から動かす」で書き出すと、発生位置を外から差し込める形になります。 吉里吉里プラグインなら名前でそのまま渡せます。

player.setDynamicInputByName("emitter.x", x)
player.setDynamicInputByName("emitter.y", y)

渡す座標は setCoord と同じ画面中央が原点・Y が下向きのピクセルです (符号合わせはエフェクト側に入っているので気にしなくて構いません)。名前の対応は ZIP に入る effect.json から読まれます。記録した軌道も motion/*.json として同梱されるので、どれを流すかは組み込み先で選べます。

  • 小さくて目立たない … 効くのは「大きさ > 密度 (発生数 × 寿命) > 加算の重なり」の順です。発生数を上げるより粒を大きくするほうが安く効きます
  • 四角い塊に見える … 開始サイズのばらつきを増やすか、形のぼかしを上げてください
  • 粒の向きが揃わない … 回転を使うと角度の基準が進行方向になります。画面に対して固定したいときは回転のパラメータをすべて 0 に
  • 枠からはみ出す … 「表示」タブの画面サイズを組み込み先に合わせてから調整してください
